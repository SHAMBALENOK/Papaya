Papaya — это веб-сервис для школьников, где собрана информация о всероссийских и региональных олимпиадах в одном удобном месте. Платформа позволяет регистрироваться, управлять профилем.

Демо-версия проекта доступна по адресу https://papaya-bm5w.onrender.com/ (запуск в docker более стабилен)
## Возможности

- **Авторизация и регистрация:**  Безопасная система входа с хешированием паролей и валидацией данных.
- `СКОРО` **JWT аутентификация:** Скоро поменяется механизм аутентификации на JWT
- **Каталог олимпиад:**  Просмотр списка активных мероприятий.
- **Изменение данных профиля:** Появилась возможность редактировать свой профиль на отдельной странице сервиса
- **Добавление и изменение событий:**  Возможность создавать и редактировать события
- `СКОРО` **Изменение данных событий:** Поменяется механизм (появится страница для этого действия) обновления и добавления событий.
- `НОВОЕ` **Вставка таблиц:** Пользователи могут вставлять информацию о олимпиадах прямо из таблиц в PDF
- `СКОРО` **Расширенная вставка:** Поддержка импорта excel таблиц и таблиц с фото
- `СКОРО` **Роли и вкладки:** Скоро появятся роли ***(студент/школьник/учитель/образовательная организация)*** с различными возможностями и распределение событий на вкладки
- `СКОРО` **Администрирование:** Скоро можно будет удобно администрировать наш вэбсервис на отдельной странице
- `СКОРО` **Свободное пользование:** Возможность пользования отдельными страницами вэбсервиса без аутентификации
- `СКОРО` **Оптимизация1:** Возможность отключить функции использующие нейронные сети для оптимизации, оптимизация кода в целом
- `СКОРО` **Оптимизация2:** Оптимизация установки нейронных сетей
- `СКОРО` **Изменения информации о соббытиях:** Теперь, чтобы не терять информацию, при импортировании олимпиад из pdf/excel/фото вся информация, которая не является необходимой для создания события будет записываться в описание
- `СКОРО` **Автоматизированные тесты** 
- `СКОРО` **Кэширование**  

## Стек технологий

- **Backend:** Python, Flask, Flask-Login
- **Database:** PostgreSQL, SQLAlchemy (ORM)
- **Контейнеризация:** Docker, Docker Compose
- **Шаблоны:** Jinja2
- **Безопасность:** Хеширование паролей, валидация через регулярные выражения, UUID для идентификаторов пользователей.

## Требования для запуска

Перед началом работы убедитесь, что на вашем компьютере установлены следующие компоненты:

- **Git** (для клонирования репозитория)
- **Docker** версии 20.10 и выше
- **Docker Compose** версии 2.0 и выше
- Доступ к интернету (требуется для загрузки образов Docker и подключения к базе данных, если используется удаленный хостинг)

## Локальный запуск

### 1. Клонирование репозитория
***Убедитесь, что у вас не включен VPN***

Склонируйте проект. Запустите Docker Desktop перейдите в его директорию:

```bash
git clone https://github.com/SHAMBALENOK/Papaya.git
cd ./path/to/Papaya
```

### 2. Запуск приложения

Выполните сборку и запуск контейнеров:

```bash
docker-compose up -d --build
```

После успешного запуска приложение будет доступно по адресу:
[http://localhost:5000](http://localhost:5000)

Для просмотра логов приложения в реальном времени:

```bash
docker-compose logs -f
```

### 3. Остановка и очистка

Чтобы остановить сервисы:
```bash
docker-compose down
```

Чтобы остановить сервисы и удалить тома с базой данных (все данные пользователей и события будут безвозвратно удалены):
```bash
docker-compose down -v
```

## API и Маршруты

Основные эндпоинты приложения:

| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/auth` | Страница авторизации/регистрации | Публичный |
| `POST` | `/auth/register` | Регистрация нового пользователя | Публичный |
| `POST` | `/auth/login` | Вход в систему | Публичный |
| `GET` | `/logout` | Выход из системы | Требуется вход |
| `GET` | `/` | Главная страница со списком олимпиад | Требуется вход |
| `GET` | `/event/<id>` | Информация об олимпиаде | Требуется вход |
| `GET` | `/user/<user_id>` | Информация о пользователе | Требуется вход |
| `POST` | `/user/<user_id>/edit_info` | Редактирование профиля пользователя | Требуется вход |
| `POST` | `/user/<user_id>/add_event` | Создание нового события | Требуется вход |
| `POST` | `/user/<user_id>/<event_id>/edit_event` | Редактирование события | Требуется вход |
| `POST` | `/user/<user_id>/add_events_via_pdf_tables` | Добавление событий через PDF таблицы | Требуется вход |
