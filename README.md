Papaya — это веб-сервис для школьников, где собрана информация о всероссийских и региональных олимпиадах в одном удобном месте. Платформа позволяет регистрироваться, управлять профилем.

Демо-версия проекта доступна по адресу: https://papaya-poxq.onrender.com
## Возможности

- **Авторизация и регистрация:**  Безопасная система входа с хешированием паролей и валидацией данных.
- `СКОРО` **JWT аутентификация:** Скоро поменяется механизм аутентификации на JWT
- **Каталог олимпиад:**  Просмотр списка активных мероприятий.
- **Изменение данных профиля:** Появилась возможность редактировать свой профиль на отдельной странице сервиса
- **Добавление и изменение событий:**  Возможность создавать и редактировать события
- `СКОРО` **Изменение данных событий:** Поменяется механизм обновления и добавления событий, а также интерфейс и, возможно, страница, где это осуществляется.
- `НОВОЕ` **Вставка таблиц:** Пользователи могут вставлять информацию о олимпиадах прямо из таблиц в PDF
- `НОВОЕ` **Автонастройка:** Вэбсервис можно настроить с помощью **setup.bat/setup.sh** (Скачивание ИИ модели для распознавания таблиц) 
- `СКОРО` **Роли и вкладки:** Скоро появятся роли (студент/школьник/учитель/образовательная организация) с различными возможностями и распределение событий на вкладки
- `СКОРО` **Администрирование:** Скоро можно будет удобно администрировать наш вэбсервис на отдельной странице
- `СКОРО` **Свободное пользование:** Возможность пользования отдельными страницами вэбсервиса без аутентификации


## Стек технологий

- **Backend:** Python, Flask, Flask-Login
- **Database:** PostgreSQL, SQLAlchemy (ORM)
- **Контейнеризация:** Docker, Docker Compose
- **Шаблоны:** Jinja2
- **Безопасность:** Хеширование паролей, валидация через регулярные выражения, UUID для идентификаторов пользователей.

## Требования для запуска

Перед началом работы убедитесь, что на вашем компьютере установлены следующие компоненты:

- **Git** (для клонирования репозитория)
- **Docker** версии 20.10 и выше
- **Docker Compose** версии 2.0 и выше
- Доступ к интернету (требуется для загрузки образов Docker и подключения к базе данных, если используется удаленный хостинг)

## Быстрый старт (только для DOCKER branch)

### 1. Клонирование репозитория

Склонируйте проект и перейдите в его директорию:

```bash
git clone https://github.com/SHAMBALENOK/Papaya.git
cd Papaya
```

### 2. Настройка переменных окружения

В корне проекта создайте файл `.env`. 

Создайте файл `.env` со следующим содержимым (замените значения на свои или используйте примеры для локального теста):

```ini
# Секретные ключи приложения
# Сгенерируйте уникальные ключи командой: python -c "import secrets; print(secrets.token_urlsafe(48))"
FLASK_SECRET_KEY=ваш_секретный_ключ_flask
JWT_SECRET_KEY=ваш_секретный_ключ_jwt

# Настройки подключения к базе данных
# Для локального запуска через docker-compose обычно используются значения ниже:
DB_USER=postgres
DB_PASSWORD=postgres
DB_HOST=postgres
DB_PORT=5432
DB_NAME=testdb

# Переменные для инициализации тестового события при первом запуске
INIT_EVENT_ID=111
INIT_EVENT_NAME=my_event
INIT_EVENT_PLACE=my_place
INIT_EVENT_MIN_GRADE=1
INIT_EVENT_MAX_GRADE=11
INIT_EVENT_MIN_AGE=6
INIT_EVENT_MAX_AGE=17

# Либо используйте полный URL для подключения к базе данных
# Используется для подключения к удаленной БД (например, Render, Neon)
# DATABASE_URL=postgresql://user:password@host:port/dbname?sslmode=require
```

### 3. Запуск приложения

Убедитесь, что Docker Desktop запущен. Затем выполните сборку и запуск контейнеров:

```bash
docker-compose up -d --build
```

После успешного запуска приложение будет доступно по адресу:
[http://localhost:5000](http://localhost:5000)

Для просмотра логов приложения в реальном времени:

```bash
docker-compose logs -f
```

### 4. Остановка и очистка

Чтобы остановить сервисы:
```bash
docker-compose down
```

Чтобы остановить сервисы и удалить тома с базой данных (все данные пользователей и события будут безвозвратно удалены):
```bash
docker-compose down -v
```

## Структура проекта

```text
Papaya/
├── .env                  # Переменные окружения 
├── .gitignore            # Правила игнорирования файлов
├── main.py               # Основной код
├── database/
│   ├── __init__.py
│   └── database.py       # Модели SQLAlchemy (Users, Events), миграции и функции доступа к БД
├── middlewares/
│   ├── __init__.py
│   ├── parse.py          # Утилиты парсинга (для будущих проектов)
│   ├── re_check.py       # Валидация данных (email, пароль, имя) через регулярные выражения
│   └── tokenz.py         # Логика работы с токенами
├── templates/
│   ├── auth.html         # Страница входа и регистрации
│   ├── main.html         # Главная страница со списком событий
│   ├── event_detail.html # Шаблон детального просмотра события
│   └── RottedPapaya.html # Дополнительные шаблоны
└── docker-compose.yml    # Конфигурация Docker контейнеров (App + Postgres)
```

## API и Маршруты

Основные эндпоинты приложения:

| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/auth` | Страница авторизации/регистрации | Публичный |
| `POST` | `/auth/register` | Регистрация нового пользователя | Публичный |
| `POST` | `/auth/login` | Вход в систему | Публичный |
| `GET` | `/logout` | Выход из системы | Требуется вход |
| `GET` | `/` | Главная страница со списком олимпиад | Требуется вход |
| `GET` | `/event/<id>` | Информация об олимпиаде | Требуется вход |
