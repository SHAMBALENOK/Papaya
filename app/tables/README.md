# Каталог файлов

* `docs/` — загруженные администратором документы-источники (PDF, XLSX,
  изображения РСОШ). Каталог задаётся переменной `DOCS_DIR`; путь к файлу
  хранится в `docs.storage_key`. Из этих файлов импорт РСОШ берёт данные
  каталога олимпиад.
* `rsosh_bvi/` — пример реального документа РСОШ (PDF): его можно
  загрузить в админке и посмотреть, как работает импорт, preview и
  подтверждение.

Временные промежуточные файлы (рендер страниц, превью) не сохраняются: они
создаются и удаляются в рамках одного импорта.
