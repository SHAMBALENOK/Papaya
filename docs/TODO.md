# 🥭 Papaya — что уже сделано и что дальше

> Документ описывает состояние проекта **после** приведения к продуктовой
> концепции и следующие шаги. Он не содержит исторического плана: старые идеи
> (календарь олимпиад, этапы и даты, редакции олимпиад, ML-рекомендации,
> справочник организаторов, трекер участия) в текущем этапе сознательно не
> реализуются. Организатор олимпиады при этом хранится как свободный текст
> `organizer` и справочником не становится.

## Продуктовая концепция (зафиксирована)

> **«Какие олимпиады дают БВИ в нужном мне университете?»**

```text
Университет → олимпиады, дающие БВИ → информация об олимпиаде → официальный сайт
```

Papaya — агрегатор, каталог университетов, каталог олимпиад и связь
университетов с олимпиадами через БВИ. Это не система поступления, не
календарь олимпиад и не социальная сеть.

## Текущий этап — закрыт

### Доменная модель

- [x] `universities` — каталог университетов: полное название, краткое название,
      описание, официальный сайт, две картинки (`preview_image` для карточек и
      `image` для страницы), нормализованное имя (защита от дублей).
- [x] `olympiads` — единый каталог олимпиад: название, описание, официальный
      сайт, две картинки, источник информации, организатор свободным текстом
      (`organizer`), статус актуальности (`PUBLISHED` / `ARCHIVED`), причина
      архива (`RSOSH_ABSENT` / `MANUAL`), документ-источник.
- [x] `university_olympiads` — связь «университет даёт БВИ за олимпиаду» со
      статусом заявки (`PENDING` / `CONFIRMED`) и уникальностью по паре.
- [x] `docs` — документы-источники: файл или ссылка, тип, контрольная сумма,
      состояние обработки, раздел `metadata['rsosh']` с прогоном импорта.
- [x] `users.university_id` — привязка представителя университета.
- [x] Инвариант роли: `EDITOR` невозможен без университета — проверка в
      приложении и CHECK-ограничение в БД (миграция `0006`).
- [x] Единственный способ сменить роль вместе с привязкой:
      `POST /api/v1/admin/role/{id}`. Легаси-маршрут `/admin/university/{id}`
      и класс `UniversityAssignment` удалены.
- [x] Валидация ссылок каталога (`website`, `official_url`, `preview_image`,
      `image`): только `http`/`https`, `javascript:`/`data:`/
      `file:` и строки без схемы отклоняются.
- [x] `events` (старая сущность) перенесена в `olympiads` и удалена
      (миграции 0004–0005).
- [x] Физического удаления каталога нет нигде: олимпиада и университет только
      архивируются, чтобы не разрушать подтверждённые связи и источник.

### Каталоги и поиск

- [x] Публичные каталоги университетов и олимпиад с карточками.
- [x] Поиск по названию, краткому названию, описанию (регистронезависимо,
      переносы строк в ячейках не мешают).
- [x] Единый поиск по обоим каталогам `GET /api/v1/search`.
- [x] Страницы университета и олимпиады, двусторонний показ связей БВИ.
- [x] Публичный источник данных олимпиады `GET /api/v1/olympiads/{id}/source`:
      всегда `200`, ровно два пользовательских поля (`title`, `has_file`),
      внутренний `source_doc_id` публично не отдаётся.
- [x] Краткое название выше полного в карточках, каталоге и заголовках страниц;
      полное название не прячется.
- [x] На главной университеты — главный раздел (каталог БВИ), олимпиады —
      вторичный; убраны служебные даты и текст про вузы «из РСОШ».

### Роли и права

- [x] `USER`, `EDITOR` (представитель университета), `ADMIN`.
- [x] Object-level доступ: представитель управляет только своим университетом.
- [x] Модерация: представитель заявляет связь, администратор подтверждает.
- [x] Права на связи: представитель отзывает только `PENDING`, снятие
      `CONFIRMED` — только администратор.
- [x] Модерация без искусственных переходов: `confirm` / `reject` / `revoke`;
      перехода `CONFIRMED → PENDING` нет, отзыв удаляет связь.
- [x] Исторические связи: подтверждённая связь с архивной олимпиадой
      сохраняется и помечается `is_historical`; в интерфейсе это «Архивная
      олимпиада» / «Историческая связь», а не «БВИ».
- [x] Публичная модель олимпиады минимальна: `name_norm`, `source_doc_id`,
      `createdAt`, `updatedAt`, `archive_reason` наружу не отдаются.
- [x] Архивная причина — внутреннее значение: посетитель видит `status` и
      понятный текст, панель администратора — точную причину.
- [x] Архивная олимпиада не принимает новых заявок БВИ (409), но сохраняет
      подтверждённые связи.
- [x] `confirmedBy` очищается вместе с переводом связи в `PENDING`.
- [x] Защита от потери доступа: последнего активного администратора нельзя
      заблокировать или понизить (409). Проверка атомарна — под блокировкой
      строк администраторов, поэтому параллельные операции не оставят систему
      без `ADMIN`.
- [x] Публичный доступ к каталогам без регистрации.

### Импорт РСОШ

- [x] XLSX: нативное чтение ячеек, многострочные и объединённые ячейки.
- [x] PDF с текстовым слоем: разбор структуры документа.
- [x] Сканы и изображения: предобработка, OCR (Tesseract `rus+eng`).
- [x] Определение ориентации страницы (OSD + сравнительный OCR) и наклона.
- [x] Реконструкция таблиц по геометрии, многостраничные таблицы.
- [x] Нормализация ячеек, зеркальная шапка РСОШ, отбрасывание служебных строк.
- [x] Валидация и оценка качества распознавания по страницам.
- [x] Дедупликация: точное совпадение, близкое совпадение, пометка
      сомнительных записей для проверки.
- [x] Preview, частичное подтверждение (`skip`), отклонение результатов.
- [x] Архивирование олимпиад, исчезнувших из перечня РСОШ, с причиной
      `RSOSH_ABSENT`.
- [x] Ручной архив с причиной `MANUAL`; вернуть «нет в перечне РСОШ» вручную
      нельзя — вернёт импорт.
- [x] Снятый в preview кандидат не архивирует существующую олимпиаду.
- [x] Фоновый запуск в Celery с fallback на выполнение в процессе API.
- [x] Старый массовый импорт таблиц недоступен: маршрут, код и UI удалены.

### Инфраструктура

- [x] Alembic-миграции, применяемые при старте; `ensure_db_schema.py` создаёт
      отсутствующую базу.
- [x] Версионный кэш профилей в Redis; каталоги читаются из PostgreSQL.
- [x] Health/readiness-маршруты, Docker healthcheck.
- [x] Автотесты: бизнес-логика, права, все форматы импорта, дедупликация,
      архивирование.

### MVP hardening

- [x] Правила льгот: публичная выдача только `verified + is_published`,
      фильтры `university_id` / `olympiad_id` / `season_id` / `program_id` /
      `benefit_type` / `subject` / `search`, пагинация с `total`.
- [x] Рабочий кабинет представителя: `/manage`-маршруты показывают черновики,
      историю версий и историю проверки; публичные маршруты остаются
      публичными.
- [x] Проверка правила — только администратором и только при наличии
      документа-основания и ссылки на источник.
- [x] Правка содержания проверенного правила (включая набор программ) снова
      отправляет его на проверку.
- [x] Оптимистичная блокировка: `SELECT ... FOR UPDATE` и `409` при
      параллельной правке; версии и откат сохраняются в истории.
- [x] Заявки представителей, аудит действий пользователей и администраторов;
      ошибки записи аудита логируются, но не роняют основную операцию.
- [x] Документы университета: представитель загружает и переименовывает
      приказы/положения своего вуза, указывает автора загрузки и скачивает
      только свои файлы.
- [x] Сезоны, профили и образовательные программы: создание, публичный
      каталог, поиск, архивирование без физического удаления.
- [x] Панель администратора: сводка, списки университетов, программ, сезонов,
      документов, импортов и правил льгот; архивирование и восстановление,
      подтверждение и отклонение правил.
- [x] Журнал запусков импорта РСОШ: кто и когда запустил, чем закончилось,
      построчные результаты подтверждения.
- [x] Публичный каталог льгот (`#/benefits`, `GET /benefits`) и блок
      «Проверенные льготы» на странице олимпиады: только `verified +
      is_published`.
- [x] `is_published` как отдельный тумблер представителя: скрытие из каталога
      не снимает `verified` и не требует повторной модерации.
- [x] Справочник источников `Source`: администратор ведёт общие и вузовские
      источники, представитель привязывает доступный источник к правилу;
      удаление источника оставляет правило с документом и ссылкой.
- [x] Организатор олимпиады (`organizer`) в формах создания/правки, каталоге и
      публичной карточке — свободный текст без отдельной сущности.
- [x] Админ-документы с поиском, фильтрами и пагинацией; аудит с фильтрами по
      действию и типу сущности; история импортов с построчными результатами.
- [x] Миграция `0013`: новые поля, индексы, CHECK-инварианты, уникальность
      сезона и версии правила; существующие дубли сезонов разводятся
      автоматически.

## Следующие шаги (после MVP)

Приоритеты — от наибольшей пользы для сценария к меньшей.

### P0 — качество данных каталога

- [ ] Массовое обновление официальных сайтов олимпиад (сейчас заполняется
      вручную) — через импорт поля «ссылка», если оно появится в документах.
- [ ] Скрипт первичного наполнения каталога из актуального перечня РСОШ
      (разовый прогон импорта с подтверждением).

### P1 — качество использования

- [ ] Поиск с подсказками и ранжированием (частотность запросов, `pg_trgm`).
- [ ] Страница «олимпиады, которые дают БВИ в N университетах» — обзор по
      направлениям без новых сущностей.
- [ ] Счётчики БВИ-олимпиад на карточках (простое производное значение из
      подтверждённых связей).
- [ ] Экспорт списка олимпиад университета (CSV/PDF) для внутреннего
      использования вузами.

### P2 — эксплуатация

- [ ] Rate limiting и security headers на публичных маршрутах.
- [ ] Структурированные логи и метрики импорта (длительность, страницы,
      уверенность распознавания).
- [ ] Проверка CORS/CSRF и полное описание OpenAPI.
- [ ] CI: прогон тестов и линтера на каждый push.

### Отложено осознанно

Не входит в текущий этап и не планируется без отдельного решения:
календарь и этапы олимпиад, даты и дедлайны, результаты, факультеты,
школы, избранное, рекомендации (в том числе ML), личный трекер участия,
мобильное приложение, социальные функции, платежи.

> Слово «приобрести» в интерфейсе — пользовательская терминология: сервис
> не продаёт и не принимает оплату, он фиксирует связь «университет даёт БВИ
> за олимпиаду».
