# Возможности

[← Документация](README.md) · [К README проекта](../README.md) · [English](en/features.md)

## Реализовано

- публичные каталоги университетов и олимпиад с поиском (регистр, переносы
  строк, частичные совпадения);
- единый поиск по обоим каталогам `GET /api/v1/search?q=…`;
- страницы университета и олимпиады, двусторонняя связь БВИ;
- заявки представителя университета и модерация заявок администратором;
- ручное создание и правка университетов и олимпиад администратором;
- архив олимпиад и автоматическое архивирование исчезнувших из перечня РСОШ;
- загрузка документов-источников и импорт РСОШ с preview и подтверждением;
- импорт официального перечня РСОШ: XLSX-таблица, план с сезонами и профилями,
  правка плана, атомарное применение и история изменений;
- аутентификация (JWT в HttpOnly-cookies), профили, роли и object-level доступ;
- версионный кэш профилей в Redis; каталоги читаются напрямую из PostgreSQL,
  чтобы пользователь не видел устаревшую карточку после правки;
- health/readiness-маршруты и Docker healthcheck;
- миграции Alembic, применяемые автоматически при старте;
- автотесты: бизнес-логика, права, все форматы импорта (XLSX, PDF, скан,
  поворот, изображение), дедупликация и архивирование.

## Не реализовано сознательно

Это следующие шаги, а не MVP: расписание и этапы олимпиад, дедлайны,
результаты, сезоны/издания, дополнительные типы льгот сверх `BVI`, `EGE_100`,
`DVI_100` и `OTHER`, организаторы, школы, рекомендации, мобильное приложение,
платежи.
